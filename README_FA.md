# 7East SMS Controller — نسخهٔ اندروید

این پروژه یک اپ اندرویدی ساده و مستقل برای کنترل قسمت پیامکی فریمور ESP32 + SIM800 است. رابط به‌صورت تیره و راست‌چین طراحی شده تا حال‌وهوای وب‌سرور 7East را داشته باشد.

## امکانات

- نمایش ۴۰ رله در کارت‌های رنگی؛ سبز = روشن، خاکستری = خاموش، کهربایی = پالس/نامشخص.
- نام‌گذاری محلی هر رله (مثلاً «چراغ آشپزخانه») و هر رجیستر. نام‌ها فقط روی گوشی ذخیره می‌شوند و به ESP32 ارسال نمی‌شوند.
- دکمهٔ «رفرش همه» فرمان `STATUS` را می‌فرستد، پس از دریافت پاسخ، به‌صورت خودکار `VARS` را درخواست می‌کند.
- فیدبک پیامکی `Coil N = ON/OFF/Pulse` و پاسخ‌های `STATUS` و `VARS` خوانده و در رابط اعمال می‌شوند.
- نوشتن مقدار رجیستر با فرمان `SET N VALUE` و منتظر ماندن برای پاسخ `RegN = VALUE`.
- تب مدیریت شامل `LIST`, `ABOUT`, `ADOTP`, `USOTP`, `ADUS`, `DELUS`, `ADAD`, `DELAD`, `SETID` و کنترل دستی `PULSE N` است.
- برای جلوگیری از ارسال پشت‌سرهم، در هر لحظه فقط یک درخواست منتظر پاسخ می‌ماند. مهلت پاسخ ۹۰ ثانیه است. اگر پاسخ نرسد، برنامه فرمان تغییر وضعیت را خودکار تکرار نمی‌کند تا رله ناخواسته دوبار Toggle نشود.
- اگر وضعیت رله نامشخص باشد، اولین لمس آن رله فقط وضعیت را Refresh می‌کند؛ این کار از Toggle ناخواسته جلوگیری می‌کند.
- پیامک ورودی با مجوز اندروید دریافت می‌شود؛ لازم نیست برنامه Inbox کل گوشی را بخواند.

## ساخت و اجرا

1. Android Studio را نصب کنید و در صورت درخواست، Android SDK Platform 35 و JDK 17 را نصب کنید.
2. در Android Studio از **Open** پوشهٔ `7East_SMS_Controller` را انتخاب کنید.
3. اجازه دهید Gradle Sync تمام شود؛ این پروژه کتابخانهٔ UI خارجی ندارد.
4. گوشی اندرویدی را وصل کنید و **Run** را بزنید، یا از منوی **Build → Build APK(s)** فایل APK بسازید.
5. در اولین اجرا، مجوزهای **Send SMS** و **Receive SMS** را تأیید کنید.
6. شمارهٔ سیم‌کارت نصب‌شده روی SIM800 را در کادر بالای برنامه وارد کنید. این شماره، شمارهٔ گوشی کنترلر است؛ نه شمارهٔ گوشی اندرویدی.
7. شمارهٔ گوشی اندرویدی باید در فریمور ثبت‌شده و مجاز باشد. برای استفاده از دستورات مدیریتی، باید سطح دسترسی آن شماره ADMIN باشد.
8. دکمهٔ «رفرش وضعیت» را بزنید. پس از دریافت `STATUS` و `VARS`، رله‌ها و رجیسترها نمایش داده می‌شوند.

## ملاحظات سازگاری

- اپ با فرمان‌های همین فریمور هماهنگ است: شمارهٔ `1` تا `40` برای کنترل رله، `STATUS`, `VARS`, `SET N VALUE`, `PULSE N` و دستورات مدیریتی مذکور.
- فرمان عددی رله در فریمور فعلی **Toggle** است؛ به همین دلیل اپ قبل از کنترل، وضعیت شناخته‌شده را می‌خواهد و پس از ارسال منتظر پاسخ می‌ماند.
- وضعیت‌ها تنها وقتی از پیامک برگشتی یا درخواست Refresh داده برسد به‌روز می‌شوند. اگر وضعیت یک رله از طریق Modbus و بدون پیامک تغییر کند، اپ تا رسیدن پیامک یا Refresh بعدی از آن تغییر باخبر نمی‌شود.
- اگر پیامک پاسخی نرسد، برنامه آن را به‌طور خودکار دوباره ارسال نمی‌کند. ابتدا وضعیت را Refresh کنید و سپس دوباره اقدام کنید.
- این پروژه **منبع Android Studio** است؛ در محیط ساخت این فایل‌ها Android SDK و Gradle موجود نبود، بنابراین APK کامپایل‌شده و تست سخت‌افزاری ادعا نمی‌شود.

## ساختار

- `app/src/main/java/com/seveneast/smscontroller/MainActivity.java` — رابط کاربری، ارسال فرمان، قفل تراکنش، و پردازش فیدبک.
- `SmsReceiver.java` — دریافت پیامک‌های ورودی از SIM800 حتی وقتی صفحهٔ برنامه باز نیست.
- `SmsSentReceiver.java` — دریافت گزارش تحویل پیامک به لایهٔ ارسال اندروید.


## رفع خطای یافت نشدن پلاگین اندروید

اگر Gradle خطای یافت نشدن `com.android.application` نسخه `8.7.3` داد، فایل `settings.gradle.kts` این نسخهٔ بسته مستقیماً ماژول `com.android.tools.build:gradle` را resolve می‌کند تا جستجوی plugin-marker دور زده شود. دسترسی شبکه به مخزن Aliyun/Google Maven همچنان لازم است. برای این پروژه از Gradle 8.9 و JDK 17 استفاده کنید.
